## מידות

```
M   55.35 × 48.80 מ"מ    לוח 55.35 × 37.80, פתח 49.95 × 32.40
S   38.08 × 33.62 מ"מ
עובי חומר 4.5 · עומק סגור 22.0 · כובע 32.0 רוחב · 5 שיניים, פסיעה 11.1, אורך 7.0
דופן מינימלית: 2.70 (M) · 2.20 (S)
```

המונוגרמה בקנה מידה 0.27 מ"מ ליחידת לוגו, כלומר עובי הקו u=10 הופך ל-2.70 מ"מ.

## שלוש התאמות שהיו חייבות לקרות כדי שזה ייוצר

1. **מסגרת.** בלוגו, חוד ה-V והרגליים נגמרים באוויר. בקליפס הם חייבים להיאחז
   במשהו — לכן הלוח מוקף מסגרת בעובי קו אחד, והחודים חודרים לתוכה 1.1 מ"מ.
2. **השקה → חיבור אמיתי.** ה-O והמעוין נגעו ברגליים בנקודה אחת. נקודה נשברת.
   הם הוזזו 0.8 מ"מ פנימה כך שיש חפיפה אמיתית.
3. **מידה S אינה הקטנה של M.** הקטנה ישירה מורידה את הדופן ל-1.83 מ"מ והחומר
   נשבר. הקובץ נוצר בהקטנה 0.68 ועיבוי 0.22 מ"מ לכל שפה → דופן 2.27 מ"מ.

כל שש הגרסאות עברו בדיקת שחיקה אוטומטית: הצורה נשארת חתיכה אחת מחוברת גם אחרי
כרסום 1.0 מ"מ מכל שפה, כלומר אין שום צוואר דק מ-2.0 מ"מ.
