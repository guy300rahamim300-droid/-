## הערה טכנית

הקבצים בנויים כ-`stroke` ולא כמתארים מלאים (outlines) — זה מה שמאפשר לשנות
עובי בשורה אחת. לפני ייצור (רקמה, חיתוך, חלק מבתי הדפוס) צריך להמיר
ל-outlines: ב-Illustrator זה `Object › Path › Outline Stroke`.
תגיד איזה מספר נבחר ואני מוציא גרסה מומרת + נעילות וגדלים.
