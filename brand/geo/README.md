# VELOURÉA — משפחת סימנים גאומטריים

18 סימנים, כולם על **הגריד של הלוגו המקורי בדיוק**, בלי שינוי פרמטר אחד:

```
u = 10   עובי קו אחיד (monoline)        H = 120 (12u)       W = 185
p = 55   מרווח צירי הרגליים             חצי־רוחב הגוף = 50  →  משיק לרגל (50 = 55−5)
R = 30 (=H/4)   r = 20   d = 20 (היסט מרכז הקשת → מקטע ישר 2u)
Rb = 17.5 / 7.5                          α = 30° שיפוע הלהב, חוד ב-x = ±92.5
```

שיקוף כפול: מצויר חצי ימני אחד, `scale(-1 1)` יוצר את השמאלי. החצי חוצה מעט
את ציר האמצע כדי ששני העותקים יחפפו — בלי תפר.

## אוצר המילים

| מודול | מה זה | האות |
|---|---|---|
| להב | קו ב-30° שנפגש בחוד על ציר האמצע | **V** |
| קורה | קו אופקי 1u או 2u | **L** (הכף) |
| טבעת obround | מלבן + שני חצאי עיגול | **O** של velOurea |
| מעוין | V מעל V הפוכה | **V** שוב |
| vesica | טבעת מחודדת משני קשתות | חוד ה-V בצורה רכה |

אין כאן **R** ואין **B** — שתי האותיות שמחזירות ישירות למקור.
