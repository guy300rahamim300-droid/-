# VELOURÉA — איך השם נכנס לסימן

הסימנים הקודמים ב-`brand/` היו גאומטריה יפה אבל אי אפשר היה להצביע ולהגיד
"הנה ה-V". התיקייה הזו מתקנת את זה: בכל אחד מהסימנים כאן האות נקראת.

## המבנה — שלוש שכבות, כמו בכל מותג גדול

| שכבה | קובץ | איפה משתמשים |
|---|---|---|
| **סימן ראשי** | `velourea-mark-01/02.svg` | קליפס, כפתור, פאביקון, חותם |
| **מונוגרמה / קישוט** | `velourea-mark-03/04/08.svg` | דפוס חוזר, בטנה, נייר עטיפה |
| **וורדמארק** | `velourea-wordmark.svg` | כל מקום טיפוגרפי |

## שמונה האפשרויות

| # | שם | ההיגיון |
|---|---|---|
| 01 | **V — Solo** | האות הראשונה, לבד. הכי עמיד לאורך זמן, הכי טוב בקטן |
| 02 | **VÉ — Accent** | V עם הטעם החד. ה-É של VELOURÉA הוא נכס: כמעט אף מותג בקטגוריה לא מחזיק אות מוטעמת |
| 03 | **V — Nested** | V בתוך V. מחזיר את תחושת המונוגרמה בלי לוותר על קריאוּת |
| 04 | **V — Fold** | חריץ אחד לאורך הזרוע — קפל קטיפה, קו האור על בד ולור |
| 05 | **V·O — Seal** | ה-V בתוך טבעת. לחותם שעווה, לתג מתכת |
| 06 | **VLR — Ligature** | שלוש ראשי התיבות, זקופות וקריאות. R רגילה לחלוטין |
| 07 | **V — Plaque** | ה-V בתוך הלוח — אותו לוח בדיוק שהופך לקליפס |
| 08 | **V·A — Bookend** | האות הראשונה והאחרונה. שומר על המראה, מדייק את הקריאה |

## הוורדמארק

מונוליין גאומטרי, גובה אות 60 יחידות, עובי קו 7, ריווח 17 — ריווח רחב הוא
מה שנותן את תחושת היוקרה. כל אות בנויה מאותה ערכת כלים של הלוגו: גזעים,
קערות obround, אלכסונים. אין כאן גופן מדף — האותיות שלך.
