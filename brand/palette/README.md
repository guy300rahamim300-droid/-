## המדידה שקבעה הכול

מדדתי את הוורדמארק הקיים שלך פיקסל־פיקסל:

```
גובה אות (cap)  116 px        עובי קו  23 px        →  19.8%
הסימן הגאומטרי שבנינו קודם     u=10 / H=120         →   8.3%
```

**פי 2.4 הפרש.** סימן דק ליד אותיות כבדות לא נראה כמו שני חלקים של אותו
מותג, הוא נראה כמו שני מותגים. לכן הסימן נגזר מחדש — לא הועבה, אלא נבנה
מחדש מהגריד כלפי מעלה:

```
u = 24 (20.0% מ-H)   H = 120   W = 228   p = 67
טבעת: חצי־רוחב 55, חלל פנימי 62  →  חלל/גובה = 0.51, בדיוק כמו ה-O שלך
להב 30°, חוד ב-x = ±114
```

`00-weight-proof.svg` מראה את ההבדל: למעלה לפני, למטה אחרי.

## שני דברים שכדאי שתדע

1. **הוורדמארק כאן הוא וקטור שחילצתי מה-PNG** — התאמה של 96% למקור, 383
   נקודות. אם יש לך את הקובץ המקורי עם הגופן, **תשתמש בו** ולא בזה. הווקטור
   הזה הוא רשת ביטחון, לא תחליף למקור.
2. **ה-VLR נבנה מהאותיות שלך.** חילצתי את ה-V, ה-L וה-R מתוך הוורדמארק עצמו
   והרכבתי מחדש. זו לא הקלדה בגופן דומה — אלה בדיוק אותן צורות.
